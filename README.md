# Indo Jaya Gram Website

Next.js landing page for Indo Jaya Gram - 3-agent operating system for web agencies.

## Setup

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

## Files

- `pages/index.js` — Main landing page
- `package.json` — Dependencies
- `next.config.js` — Next.js config
